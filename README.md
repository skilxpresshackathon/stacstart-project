DISCOVER

A video-first marketplace for discovering local service providers and booking their services.

PROJECT

Discover helps customers find service providers through short videos, view their profiles and request services.

Providers can showcase their work, manage service requests, manage their profiles and complete the verification process.

TECH STACK

- React
- TypeScript
- Vite
- Supabase
- Tailwind CSS

PROJECT STRUCTURE

src/
├── components/
├── layouts/
├── pages/
├── hooks/
├── lib/
├── services/
├── types/
└── assets/

DEVELOPMENT

Install dependencies:

npm install

Start the development server:

npm run dev

Run linting:

npm run lint

Build the application:

npm run build
